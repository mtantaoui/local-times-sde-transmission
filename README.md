# On inhomogeneous stochastic differential equations involving local times and partial differential equations with transmission condition

Master's thesis (M2PA, Cadi Ayyad University, Marrakech, 2018), by
Mohamed Al Mahdi Tantaoui, supervised by Brahim Boufoussi.

**[Download the PDF](https://github.com/mtantaoui/local-times-sde-transmission/releases/latest/download/local-times-sde-transmission.pdf)**

This is a revised version. The mathematical errors of the 2018 text have been
corrected, several proofs completed and references added; see
[ERRATA.md](ERRATA.md) for the full list of changes.

## Abstract

This thesis studies one-dimensional stochastic differential equations involving
the local time of the unknown process, together with the partial differential
equations with transmission condition associated with them.

1. **Local times of semimartingales**: Tanaka and Itô–Tanaka formulas, occupation
   times formula, regularity in the space variable, down-crossings, symmetric local
   time.
2. **SDEs involving the local time at zero**:
   $X_t = x + B_t + \int_0^t \alpha(s)\,dL_s$, with pathwise uniqueness for
   $\alpha \le 1/2$ (Le Gall's method), and an extension to general coefficients.
3. **SDEs involving the local times of the unknown process**, following Le Gall
   (1984): existence and pathwise uniqueness, limit theorems, comparison theorems.
4. **Parabolic PDEs**: the heat equation and the Feynman–Kac formula via Brownian
   motion.
5. **Skew Brownian motion**: construction by random flipping of excursions, joint
   law of the process and its local time, transition density, and the heat equation
   with transmission condition
   $(1+\beta)\,\partial_x u(t,0^+) = (1-\beta)\,\partial_x u(t,0^-)$.

## Building

You need a TeX Live installation (pdfLaTeX, BibTeX, the `memoir` class).

```sh
latexmk            # builds main.pdf
latexmk -c         # removes auxiliary files
```

Without `latexmk`: `pdflatex main && bibtex main && pdflatex main && pdflatex main`.

The figure `figures/downcrossings.pdf` is generated by a script (Python 3 with
NumPy and Matplotlib); it is committed, so you only need this to change it:

```sh
python figures/downcrossings.py
```

Each push to `main` builds the PDF in GitHub Actions. Pushing a tag `v*` also
publishes it as a GitHub release.
